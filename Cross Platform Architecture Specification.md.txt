Technical Architecture Specification: Unified Cross-Platform System
Author: Technical Architecture Team
Target Platforms: Web, Desktop (macOS, Windows, Linux), Mobile (iOS & Android)
Core Technologies: React, Electron, React Native, TypeScript, Turborepo
________________


1. Executive Summary
This document defines the unified, cross-platform technical architecture designed to target Web (React DOM), Desktop (Electron), and Mobile (React Native / Expo) from a single, cohesive code repository.
By establishing a clear separation between Shared Business Logic (APIs, state management, validation, domain models) and Platform-Specific UI Rendering, this architecture achieves ~70–80% code reuse across all client applications. This minimizes development overhead, guarantees state consistency across devices, and ensures high performance by using native rendering engines where appropriate.

3. Technology Stack & Strategy
Category
	Technology Selected
	Justification
	Monorepo Engine
	Turborepo + pnpm
	Ultra-fast incremental builds, remote caching, and strict workspace isolation.
	Language
	TypeScript (v5+)
	Strict typing across shared models, APIs, and client-side code.
	Global State
	Zustand
	Minimal boilerplate, platform-agnostic, and works seamlessly across React DOM and React Native.
	Server State / Cache
	TanStack Query (React Query)
	Automatic caching, re-validation, offline persistence, and synchronized network fetching.
	Web Platform
	React DOM + Vite + Tailwind CSS
	Lightning-fast HMR, lightweight output bundle, and modern utility-first CSS styling.
	Desktop Platform
	Electron
	Wraps the web application, providing native OS integration, IPC communication, and local file access.
	Mobile Platform
	React Native + Expo
	Direct compilation to native iOS (UIKit) and Android (Views) components with direct access to device hardware.

5. Reference Code Implementations
A. Shared Business Logic & State (packages/shared/src/store/useAppStore.ts)
import { create } from 'zustand';


interface AppState {
  activeUnitId: string | null;
  connectionStatus: 'connected' | 'disconnected' | 'connecting';
  setActiveUnit: (id: string) => void;
  setConnectionStatus: (status: 'connected' | 'disconnected' | 'connecting') => void;
}


export const useAppStore = create<AppState>((set) => ({
  activeUnitId: 'UNIT-01',
  connectionStatus: 'connected',
  setActiveUnit: (id) => set({ activeUnitId: id }),
  setConnectionStatus: (status) => set({ connectionStatus: status }),
}));

import { app, BrowserWindow, ipcMain } from 'electron';
import path from 'path';


function createWindow() {
  const mainWindow = new BrowserWindow({
    width: 1280,
    height: 800,
    titleBarStyle: 'hiddenInset',
    webPreferences: {
      preload: path.join(__dirname, '../preload/preload.js'),
      nodeIntegration: false,
      contextIsolation: true,
    },
  });


  if (process.env.NODE_ENV === 'development') {
    mainWindow.loadURL('http://localhost:3000');
  } else {
    mainWindow.loadFile(path.join(__dirname, '../../web-dist/index.html'));
  }
}


app.whenReady().then(createWindow);


ipcMain.handle('get-system-info', () => {
  return { platform: process.platform, arch: process.arch };
});

Execution Commands
* Install all dependencies across packages:
pnpm install
* Run all applications concurrently:
pnpm dev
* Target individual platform builds:
   * Web: pnpm --filter web build
   * Desktop: pnpm --filter desktop build
   * Mobile: pnpm --filter mobile build

7. Deployment & Distribution Pipeline
   1. Web Deployment: Automated CI/CD pipeline building static artifacts and hosting on Vercel, AWS CloudFront, or Netlify.
   2. Desktop Distribution: Package installers (.dmg, .exe, .AppImage) generated via electron-builder and distributed via auto-updater endpoints.
   3. Mobile Distribution: Expo Application Services (EAS) pipelines building native iOS (.ipa) and Android (.aab) binaries for submission to Apple App Store and Google Play Store.
